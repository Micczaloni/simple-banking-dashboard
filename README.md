# Simple Banking Dashboard

Frontend practice / demo project — a small banking dashboard built with **HTML, CSS, and vanilla JavaScript**.

This is a learning exercise focused on DOM manipulation, dates, number formatting, and timers. Not a real bank app.

## What you can do

- Sign in with demo accounts (PLN / EUR / USD)
- See balance, income, expenses, and interest
- Browse transactions with relative dates (`Today`, `Yesterday`, …)
- Filter transactions (All / In / Out)
- Sort by date or amount
- Transfer money between demo accounts
- Request a loan (simple approval rule)
- Close an account
- Auto logout timer + manual logout
- Toast messages for success / error feedback
